# Analysis outputs

This folder includes four reviewed figures, balance and arrest regression tables, and the two-sample IV results. The main README displays the alcohol-consumption and total-arrest figures.

Running `run_all.do` regenerates these files and creates diagnostic panels, saved first-stage estimates, and a session log. Local logs, saved estimates, and unreviewed diagnostic panels are ignored by Git. The reviewed figures and tables can be committed normally.

Validation details are in [validation.md](../docs/validation.md).
